# ⚔️ Table War

역사 속 문명과 장수로 펼치는 턴제 땅따먹기 전략 게임 (React + Vite).

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 정적 빌드
```

## 시나리오
- **랜덤 대륙**: 시드로 생성되는 가상 대륙, 무작위 문명·국가 배치
- **세계사 1200년 / 동아시아 650년 / 삼국지 200년 / 유럽사 1400년 / 아프리카사 1400년**: 실제 해안선(Natural Earth)·산맥·강·사막 + 역사적 국가·군주 배치. 시드는 지역 구획을 바꿉니다.

## 규칙 요약
- **지역 숫자 = 병사 수.** 인접 지역으로 이동·공격 (최소 1명 잔류).
- **지형**: 숲 +15%, 구릉 +25%, 험산(넘기 힘든 산) +50%·AP+1, 고산은 통행 불가. 도강 -20%, 항해 -30%(항구 또는 수군 장수 필요, AP+1).
- **행동력(AP)**: 3 + 영토 6개당 1(최대 +5) + 신속 장수(최대 +2). 속국 -1, 배신 시 다음 턴 -2.
- **내정**: 징세(시장 +50%), 징병(병영 +50%), 건설(시장·성벽·항구·병영), 병력 유지비.
- **장수**: 한 판에 중복 없이 턴마다 확률 출현. 장수가 적은 나라일수록 확률↑, 강한 장수진엔 약한 장수 가중, 판을 거듭해 자주 나온 장수는 재출현 확률↓. 포로는 등용·처형·석방, 적 장수는 금으로 회유.
- **외교**: 금·영토 교환, 선물/조공 요구, 동맹(상호 공격 불가), 불가침, 속국(수입 25% 조공), 공동 공격. 불가침·종속 상대 공격 시 배신 페널티.
- **승리**: 전체 지역 60% 점령 또는 모든 국가 멸망·속국화.
