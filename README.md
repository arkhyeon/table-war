# ⚔️ Table War

역사 속 문명과 장수로 펼치는 턴제 땅따먹기 전략 게임 (React + Vite).

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 정적 빌드
```

## 시나리오
- **랜덤 대륙**: 시드로 생성되는 가상 대륙(대륙/양대륙/군도 유형), 무작위 문명·국가 배치. 섬나라 1곳 이상 보장, 3지역 이하 자투리 섬은 키우거나 제거, 산 12~18%·절벽 해안 18% 상한
- **세계사 1200년 / 동아시아 650년 / 삼국지 200년 / 유럽사 1400년 / 아프리카사 1400년**: 실제 해안선(Natural Earth)·산맥·강·사막 + 역사적 국가·군주 배치. 지도는 고정(시드는 랜덤 대륙에서만).

## 규칙 요약
- **병력·이동**: 지역 숫자 = 병사 수(천·만). 인접 지역으로 이동·공격, 지형·도강 보정.
- **바다**: 바다는 구역으로 나뉨. 승선 → 한 구역씩 항해 → 상륙(-25%), 험한 해안은 절벽 상륙(-55%, 행동력 +1). 해전·봉쇄, 제해권 보급. 바다 날씨: 풍랑·순풍·용오름·해무·폭풍.
- **시간·날씨**: 2턴 = 한 계절, 8턴 = 1년. 북쪽은 눈, 남쪽은 가뭄이 잦고 남쪽은 풍년도 잦아 손익 균형.
- **금**: 병사 1명 유지비 = 1금/턴 기준으로 모든 금액이 정수. 장수 녹봉 2,500금, 영토 15곳 초과 통치비 1,250금/곳.
- **부대 (삼국지14식)**: 지역의 ⚔️출진으로 장수+병력을 골라 부대를 만들면 지도에 부대 말이 생김. 부대를 누르고 목적지를 누르면 매 턴 내 땅으로 3칸씩 진군하다 닿으면 공격(승산 45% 미만이면 국경에서 대기, ⚔️무리해서 공격 가능). ➕보충(수비대에서), ⏹멈춤, 🏠귀환. 부대 병력도 머무는 지역을 함께 지킴.
- **계략 🧠**: 지력 50↑ 장수가 🔥화계(맞닿은 적 땅 병력 -15~25%), 🗣️유언비어(적 장수 충성 -15), 🌿매복(이번 턴 수비 +25%). 장수마다 턴에 한 번, 행동력 1, 성공률은 지력 차이로. 컴퓨터도 씀.
- **동맹 원군 요청 🆘**: 땅을 빼앗긴 동맹국이 군자금을 청함 — 보내면 호감 +20, 거절하면 -25에 동맹이 깨질 수 있음.
- **턴 체크리스트**: 지도 왼쪽 위에 위협받는 땅·충성 위험 장수·쉬는 부대·징병 가능·남은 행동력 — 누르면 바로 그곳으로.
- **⏩ 빠른 진행**: 내게 일(전투·땅 변화·제안·사건)이 생길 때까지 최대 15턴 자동으로.
- **전투 장면**: 다시보기에 양쪽 군세가 맞붙는 그림과 일기토·요격·협공·용병·성벽 배지.
- **장수 열전**: 게임이 끝나면 활약한 장수들의 전적(승리·함락·일기토·사로잡은 장수·최후).
- **병력 상한 없음**: 인구로 병력을 묶지 않음 — 금과 유지비(병사 1명당 1금/턴)가 한계.
- **장수 수련**: 장수 창 📚 — 금(레벨×2.5만)·행동력 1로 경험치 +레벨×50(다음 레벨의 절반), 장수마다 3턴에 한 번. 한 레벨 = 징병 1만 명분×레벨의 금. 컴퓨터도 금이 남으면 수련.
- **성벽 우선순위(컴퓨터)**: 싸우는 상대 쪽 국경은 병력으로, 싸우지 않는 이웃이 대군을 붙여 둔 국경은 성벽부터.
- **전선 관리**: 최근 8턴 안에 싸운 나라가 '전쟁 상대'. 이미 싸우는 중에 새 나라를 치면 평판 -5(자원병 감소, 평판 바닥이면 모두의 표적). 컴퓨터는 (지금 적들+새 적) 국력의 1.5배가 아니면 새 전선을 열지 않음.
- **요격**: 어느 땅이 공격받으면, 맞닿은 같은 나라 땅에 장수가 있는 부대가 달려와 함께 싸움(그 땅 병력의 절반, 지휘 한도의 절반까지). 부대를 어디 세워 두느냐가 곧 수비.
- **협공**: 한 턴에 두 곳 이상에서 같은 땅을 치면 각각 공격 +15%.
- **적 부대 표시**: 보이는 적 땅에 장수가 있으면 대장 이름과 이끌 수 있는 병력이 적힌 부대 말로 보임.
- **군단 (토탈워식)**: 나라를 치려면 장수가 이끄는 군단이 필요합니다. 장수 한 명 = 군단 하나, 이끌 수 있는 병력은 통솔로 정해짐(8천+통솔×800, 함께 가는 장수는 절반씩 더함). 빈 땅·도적을 칠 때도 장수가 필요(장수 없이 공격 불가). 지역 병력은 수비대. 장수에게 🎯목표를 찍으면 매 턴 내 땅으로 3칸씩 진군하다 닿으면 공격. 지도에 대장 이름 첫 글자 깃발. 장수 창에서 📜장수 모집(금·1AP, 기본 4명+땅 3곳마다 1명).
- **시작 장수**: 땅 6곳마다 장수 1명은 되게 채움(5명까지). 수도가 나라들 한가운데에 가까울수록 장수 +2(중간 +1, 변방 0) — 가운데는 인재가 모이고 변방은 진출이 느림.
- **도적단**: 빈 땅 열 곳 중 세 곳쯤(변방일수록 많이)에 그 시대·지역의 도적이 소굴을 틀고 있음(황건적 잔당·흑산적·백파적·홍건적·잇코잇키·로빈 후드 무리 등). 병력 1.8배, 수비만 하며 3턴마다 조금씩 불어남. 땅은 소탕하면 얻음.
- **해적단**: 턴당 4%(최대 2무리) 그 시대의 해적(왜구·바이킹·바르바리·카리브 해적 등)이 바다에 나타나 머물며, 센 나라 앞바다에 잘 나타나고, 매 턴 그 바다에 닿은 해안 중 가장 센 나라 땅을 침. 털고 나면 배를 몰아 바닷길 4칸 안의 다른 바다(센 나라 해안 쪽)로 옮겨 감(옆 바다 함대도 덮침). 규모는 지금 병력을 가장 많이 이끄는 장수 10명의 병력 중간값 × 등급(약한 0.6·보통 1·강한 1.4·엄청 강한 2배 = 25·40·25·10%), 대장 능력치도 그 10명의 중간값. 해적 1명 = 병사 1명으로 맞바꿔 죽음 — 수비대가 같거나 많으면 해적 전멸, 해적이 많으면 수비대 전멸 후 털어감(살아남은 해적 1명당 금 10·그 땅 세금 10턴치까지, 2명당 백성 1명 납치, 금이 모자라면 모자란 20금당 1명을 더 끌고 감·인구의 절반까지, 금이 절반도 안 나오면 시장도 불탐, 항구 불탐, 납치한 백성의 20%가 해적으로 합류). 땅은 빼앗지 않음. 장수가 이끄는 함대로 해전을 벌여도 격퇴.
- **변방 침입**: 턴당 6%(해적과 합쳐 10턴에 한 번꼴, 들이닥칠 때 국경 땅 2~3곳을 휩쓺, 도적 봉기는 없음 — 도적은 시작 때 소굴로만) 지도 바깥쪽 국경에 그 시대의 이민족(흉노·오환·선비·강족·거란·여진·훈족·마자르·타타르 등)이 쳐들어와 땅을 빼앗음. 규모는 상위 장수 10명의 병력 중간값 × 등급(해적과 같음), 대장 능력치도 그 중간값(강할수록 +4·+8). 장수 없이도 무리 전체로 움직이고 뺏은 땅마다 35%를 남겨 지킴. 변방의 큰 나라일수록 잘 당함.
- **성 수용 인원**: 성 1단계 10만, 증축하면 20만·30만(🏯 성 증축, 금·2AP). 넘는 병력은 성 밖에서 성벽 보정 없이 싸움 — 50만이면 10만만 성 이득.
- **수비 지휘 한도**: 수비도 그 땅 장수의 지휘 한도만큼만 출전(장수 없으면 수비대 2만), 나머지는 예비대. 수비군을 깨도 예비대가 한도의 절반보다 많으면 땅을 지킴(⚔️수비군 격파) — 큰 성은 여러 번 쳐야 함. 예비대가 적으면 무너져 절반이 옆 땅으로 달아남. 장수를 여러 곳에 두는 게 곧 수비.
- **징병**: 💂징병 창에서 「🗺️ 지도에서 지역 고르기」로 내 땅 여러 곳을 누르고(다시 누르면 빠짐), 지역마다 슬라이더로 인원을 정함. 뽑은 병사는 처음 고른 곳(🚩)으로 모임 — 다른 곳이나 제자리도 선택 가능. 1명당 5금, 행동력 2, 한 턴 1회, 인구 상한 없음(대신 뽑은 만큼 그 땅 인구가 1:1로 줄어 세수 감소, 해산하면 인구로 돌아옴).
- **자원병**: 인구와 무관하게 군주의 평판을 보고 모임 — 매 턴 평판×40명(평판 50이면 2천), 수도와 병영 있는 땅에 나눠 들어옴(병영 2몫, 모병·인덕 장수 보너스). 순수입 흑자일 때만, 나라가 위태로우면 적자여도 3배.
- **장수 성격·충성**: 🔥야심가는 충성이 잘 떨어지고 🛡️충신은 오름. 충성 40 미만이면 지키던 땅을 들고 영웅 봉기. 🎁포상(금, 6턴에 한 번)으로 관리.
- **군주의 죽음·계승 분쟁**: 군주는 늙어서(턴당 0.5%)·전사·처형으로 죽음. 큰 나라는 2인자(야심가·충성 낮음)가 왕위를 다퉈 나라가 둘로 갈라질 수 있음.
- **군단 명령**: 분봉한 군단마다 ⚔️자유·🛡️수비(나라는 치지 않음)·🎯○○ 공략(그 나라만 침)을 국가 카드나 군단 땅에서 지정.
- **명소 🏛️**: 인구 많은 이름난 고을(나라 수의 60%쯤). 가진 곳마다 나라 전체 세수 +5%.
- **적의 의도**: 내 땅과 맞닿아 보이는 적 대군(내 수비의 1.2배↑)에 빨간 점선 화살표.
- **레벨업 특성 선택**: 내 장수가 Lv3·5·7·9가 되면 「기존 특성 승급」과 「새 특성」 중 고름.
- **의형제 🤝**: 역사 속 의형제(유비·관우·장비 등)나 가끔(15%) 같은 나라 장수끼리 맺어짐. 함께 싸우면 공격·수비 +10%, 같은 나라에 있으면 충성 +10, 봉기할 땐 함께 떠나고, 형제를 처형하면 충성 -30.
- **사건 카드**: 가끔 선택지가 있는 사건이 옴 — 흉년, 혼인 동맹, 장수의 기습 간언, 무기 상인, 명의, 점술가, 인재 천거, 강국의 공물 요구, 잔치, 귀순병. 역사 시나리오는 허유의 투항·적벽 화공·출사표·이순신·의병·대륙 봉쇄령·쿠릴타이 같은 역사 카드도. 컴퓨터 나라도 알아서 고름.
- **변방 침입**: 나라들 한가운데서 먼 변방에 이민족(흉노·여진·바이킹 등)이나 해적(왜구·바르바리 등)이 쳐들어와 땅을 빼앗음.
- **보급·공성**: 보급 끊김 시 병력 1~10% 감소. 포위/강습, 공성병기.
- **장수**: 무관·문관, 특성 45종(Ⅰ~Ⅲ). 장수는 병사 수가 아닌 공격·방어 배율을 올림. 이름 변경 가능.
- **일기토**: 반격 > 공격 > 방어 > 반격 가위바위보, 같은 수는 서로 절반 피해. 다그닥 질주·충돌 애니메이션, 승부 결과를 크게 표시, KO 시 40% 전사. 무력 85%·지력 15%의 전장 감각 차이만큼 상대 의도를 미리 간파(힌트 표시), 상대도 내 수를 읽고 바꿀 수 있음.
- **장수 등급**: F·E·D·C·B·A·S·SR·SSR (잘하는 두 능력 70% + 평균 30%), 성장하면 갱신.
- **공평한 무작위 능력치(기본)**: 역사 장수의 성향(가장 높은 두 능력)만 살리고 수준은 무작위. 나라별 장수 점수 합을 맞춰 뛰어난 장수가 있으면 다음 장수는 약하게. 설정에서 역사 능력치로 전환 가능.
- **태수**: 주둔 장수 중 정치 최고가 태수(문관 전효과, 무관 절반) — 세수 보너스.
- **정전**: 6턴 휴전. 땅을 잃는 쪽이 원하고, 후반 1위는 거부.
- **난이도**: 쉬움/보통/어려움 — 컴퓨터 세수 -15%/0/+20%, 초기 병력 85%/100%/120%.
- **업적 10종 · 승리 요약**: 영토 추이 그래프, 최다 전공 장수, 주요 사건.
- **통일선**: 모든 육지 100% 점령(또는 모든 나라 멸망·속국화).
- **지역 크기(맵 세분화)**: 큼직하게/보통/잘게/아주 잘게 — 지역 수 약 0.6/1/2.3/4배. 세분화해도 인구·병력 총량은 비슷하게 보정, 나라 시작 영토는 비례 확대. 잘게 할수록 판이 길어짐.
- **연도별 세계사**: 기원전 220년 · 1000년 · 1200년 · 1500년 · 1800년 (타임라인에서 선택).
- **지역사**: 전국칠웅 BC 260, 포에니 전쟁 BC 218, 삼국지 200, 삼국지 225(위·촉·오·맹획·공손씨·선비), 광개토대왕 400, 동아시아 650, 유럽 1400, 아프리카 1400, 일본 전국시대 1560, 임진왜란 1592, 나폴레옹 1805.
- **실제 지명**: 역사 지도는 지명 사전(약 890곳, 시대별 옛 이름·건설/소멸 연도 반영)으로 지역 이름을 붙임. 역사 지도는 시드와 상관없이 지도·지명이 고정(시드는 장수·사건 등 게임 진행만 바꿈).
- **해협**: 간몬·쓰가루·도버·메시나·외레순·케르치·보스포루스·다르다넬스·지브롤터 등은 해협 경로로 직접 연결.
- **바다 구역**: 지역사 지도는 해안에서 8칸, 세계 지도는 5칸까지 — 동해 횡단·대서양 횡단 가능.
- **세계판 지역사**: 지역사는 모두 「🌍 전 세계」로도 시작 가능 — 무대는 잘게 나뉘고, 바깥은 그 시대의 다른 나라들(로마·파르티아·굽타·티무르·무굴 등)로 채워 뒤가 비지 않음.
- **밀도별 지역 크기**: 지명이 빽빽한 곳(일본·유럽 등)과 해안 땅은 잘게, 시베리아처럼 빈 땅은 크게 나눔.
- **험산 경계**: 험산은 타일이 아니라 경계선에 걸림(경계선 위 작은 봉우리). 그 경계로 넘으면 공격 -35%·행동력 +1(산악 장수 경감), 다른 경계로 돌아가면 페널티 없음.
- **내선 작전**: 내 땅 안 이동은 행동력 없음, 내 땅으로만 이어지면 한 번에 3칸까지.
- **안개**: 시야 밖은 바다까지 완전히 덮음. 땅이 아닌 곳(빙하·고산 등)은 이름 없음.
- **장수**: 능력치·특성 모두 무작위, 나라별 총합만 공평하게(역사 능력치 옵션 별도).
- **집결지·전선 자동 투입**: 내 지역을 🚩집결지로 정하거나 「전선 자동 투입」을 켜면, 국경에 닿지 않은 후방 병력이 매 턴 내 땅 안에서 자동 행군(행동력 없음, 각 지역 1천·수도 3천은 남김). 컴퓨터의 후방 병력 이동도 행동력을 쓰지 않음.
- **후방 징병**: 처음 고른 곳(또는 지정한 곳)으로 내 땅 3칸마다 1턴 뒤 도착. 가는 길이 끊기면 그 앞 내 땅에서 멈춤.
- **천운**: 한 나라가 육지 25%를 넘으면 가끔(언제일지 모름, 앞설수록 잦음, 한 판 최대 2번) 대반란·명장 망명·반패권 원조 중 하나가 일어남.
- **속국**: 조공 25%, 종주국과 맞닿은 적을 함께 공격, 속국 땅도 통일 100%에 포함.
- **용병**: 공격 계획 창에서 고용(장수가 함께 갈 때만, 통솔→인원, 정치→값), 그 전투만 싸우고 떠남. 컴퓨터도 돈이 넉넉하면 용병·매수를 씀.
- **매수**: 맞닿은 곳의 장수가 금으로 지역을 넘어오게 함(지력·정치·수비 장수·성벽 반영). 실패하면 금은 상대 나라로.
- **분봉**: 장수에게 이어진 땅을 맡기면 컴퓨터처럼 스스로 다스리는 군단이 됨(내 외교를 따름, 상납 없음, 「○○에 성을 쌓으려 하니 금 X」처럼 실제 할 일의 지원 요청 — 주면 바로 시행·충성↑ 거절하면 충성↓, 통일에 포함, 언제든 회수, 충성 40 미만이면 역모 가능).
- **변방 발생**: 신흥국·도적 무리는 나라들 한가운데에서 먼 변방일수록 잘 일어남.
- **도적 무리**: 황건적·산적단·왜구·해적단 등이 빈 땅에서 일어나거나 변방에 쳐들어옴. 외교 불가 대신 땅 매수·화친(8턴)·귀순(통째 흡수) 가능(돈만 받고 응하지 않을 수도), 가끔 협박. 6곳 이상이면 나라로 승격.
- **파산 예고·해산**: 다음 턴 파산이 예상되면 국가 카드에 경고, 지역에서 🏳️해산(행동력 없음). 파산하면 못 준 녹봉만큼(1명당 1금) 탈영.
- **병력 불러오기**: 지역에서 📯 → 지역마다 보낼 병력을 정해 한곳으로(행동력 1). 🚩전선 투입은 위협받는 국경 또는 고른 나라 쪽으로.
- **8할 도달**: 80%(속국 포함)에서 통일 선언으로 끝낼지 100%까지 싸울지 선택. 남은 나라들은 최후의 동맹 또는 속국 청원.
- **중원(대평야)**: (랜덤 대륙에서는 맞닿은 빈 땅 2곳을 더 갖고 시작) 수도 위치로 고른 가운데 나라(동서남북 4방향 모두에 다른 나라, 내륙, 다른 수도들과 거리 합 최소, 나라 6개당 1곳)는 장수 +3, 병력 +60%, 금 2.5배(이미 가장 큰 나라면 장수 +1·나머지 절반), 시작 땅이 대평야(세금 +20%·인구 +50%·인구 상한 +30%, 땅 주인이 바뀌어도 유지), 시작 땅을 지킬 때 「중원 결집」 수비 +20%, 세수 +15%.
- **토착 세력**: 빈 땅에도 수비병(4.5천~1만), 15%는 2~3배 강한 토호의 산채, 변방(나라들 한가운데에서 멀수록)은 최대 1.8배.
- **행동력 1.3배**.
- **바다 보급**: 바다는 보급로를 끊지 않음(적 함대가 지키는 바다만 막힘).
- **컴퓨터 전략**: 중원 나라는 15턴 안에 넉넉한 금(+50%)으로 이웃과 화친, 중원 나라는 약한 이웃과 화친하고 비슷하거나 센 맞수를 목표로, 사방이 적이면 수비병을 더 남김, 3개국 이상과 싸우면 목표 하나만 남기고 금을 얹어 불가침을 청함(거절당하면 새 전선을 열지 않고 목표만 공략), 점령 뒤 지키기 어려운 땅은 덜 노림, 약한 나라·섬은 가장 약해 보이는 해안부터 계속 상륙, 본토를 다 먹으면 병력을 해안으로 모음.
- **첫 판 안내**: 6단계 안내 카드(☰에서 다시 보기).
- **지도에서 고르기**: 징병 창·일괄 징병의 「🗺️ 지도에서 고르기」로 보낼 곳을 지도에서 바로 클릭.
- **제안 위치**: 외교 제안·요청 창에 그 나라(와 언급된 나라)만 색칠한 작은 지도.
- **관전 종료**: 한 나라(속국 포함)가 천하를 통일하면 관전 자동 진행이 멈춤.
- **후반 교착 방지**: 싸울 나라가 국경에 없으면 가장 약한 조약국과의 조약을 깨고, 금이 쌓이면 일괄 징병.
- **증원 속도**: 징병·불러오기 병력도 내 땅 3칸에 1턴 — 직접 행군과 같음.
- **통일 막바지**: 한 세력(속국 포함)이 80% 이상이면 신흥국·도적·천운이 멈추고, 작은 나라들이 스스로 속국을 청함.
- **지역 목록**: 병력·인구 순 정렬, 누르면 그 지역으로 화면 이동.
- **저장 슬롯**: 자동 저장 + 수동 슬롯 3개(☰ → 저장·불러오기, 시작 화면 → 이어하기·불러오기).
- **턴 요약**: 소식 창 맨 위에 영토·병력·국고 변화와 전투 승패, 「내 소식/세계 소식」 탭.
- **로딩 표시**: 지도 생성·턴 처리 중 진행 표시.
- **동시 턴제(이동 계획)**: 이동·공격은 계획만 세우고(병력 출발, 화살표 표시, 취소 가능) 턴 종료 때 모든 나라의 계획을 함께 처리. 목적지마다 아군 증원 먼저, 적대 부대는 큰 순으로 차례로 공격. 컴퓨터는 플레이어 계획을 모른 채 계획. 플레이어 일기토는 그 전투 차례에 창으로 진행.
- **장수 동행**: 이동 창에서 함께 갈 장수를 골라 군대와 함께 이동.
- **실제 지명 약 98%**: 지명 사전 약 890곳(도시·지방·지형) → 지명이 든 지역, 가까운 미사용 지명, 그래도 남으면 '○○ 북부' 식 방위형.
- **천도**: 금·3AP, 12턴에 한 번. 컴퓨터도 수도가 위험하면 천도.
- **랜덤 지도**: 대륙판(기울어진 타원) + 도메인 왜곡 해안선 + 굽은 산맥 줄기. 유형: 대륙들·판게아(내해)·군도·반도.
- **모바일**: 정보 패널은 바텀시트, 두 손가락 확대, 폰 화면에 맞춘 첫 화면.
- **실제 역사 연표**: 그 해가 되면 '실제 역사' 카드와 함께 이 세계의 같은 나라 영토·순위를 비교해 보여줌.
- **교착 방지**: 사방이 동맹·조약으로 막힌 컴퓨터는 가장 약한 조약 이웃과 관계를 끊고 확장. 동맹이 많을수록 새 동맹을 꺼림. 큰 지도는 행동력 상한이 지도 크기에 비례.
- **병력 그림·애니메이션**: 병력 규모별 병사 1~4명(8만↑은 군기), 대기 중 들썩임. 이동·공격하면 부대가 행군하고, 전투 지점에 💥, 점령 시 지역이 국가색으로 번쩍임. 설정에서 끌 수 있음.
- **후반 패권 경쟁**: 35턴 이후 1위(육지 22%↑)는 행동력 +1~2·적극 징병·불가침 파기까지 하며 공세. 대동맹은 30턴 이후 더 쉽게 결성되고, 연합군 공격 +10%·후방국 군자금 지원으로 역전 가능. 20턴 지나면 내분으로 와해(10턴 재결성 불가).
- **원군**: 동맹국 땅으로 병사(장수 제외)를 보내 넘겨줄 수 있음. AI도 위협받는 동맹국에 원군 파견.
- **망국의 왕**: 정복·병합으로 멸망한 나라의 군주는 승자의 장수로 귀순.
- **신흥국**: 10턴 이후 빈 땅의 봉기, 영웅 봉기, 계승 분쟁, 충성 낮은 옛 군주의 부흥으로 새 나라가 생김.
- **속국 병합**: 10턴 이상 거느린 속국을 국력 2배 이상이면 병합(행동력 2, 평판 -5).
- **전투 종류**: 야전·공성전·도하전·해협 도하·해전·상륙전·절벽 상륙전으로 구분해 다시보기에 표시.
- **사건**: 역병·홍수·지진·금광·교역 호황·해적·도적·용병단·장수 출분 등 어느 나라에나.
- **세력 균형**: 국력 평균 2배 초과 시 견제, 1위가 2.5배 초과이면서 육지 35% 이상일 때만 대동맹 (모든 시나리오 공통 — 중원의 나라가 초반부터 몰매 맞지 않게).
- **이간계**: 금과 행동력 1로 두 나라를 이간 — 성공하면 둘의 호감 -35, 절반 확률로 동맹·불가침 파기. 들키면 둘 다 나를 미워함. 지력 높은 장수가 있을수록 잘 됨. 컴퓨터도 사방이 적이면 씀.
- **역사 강역**: 역사 시나리오는 그 시대 실제 판도대로 시작 (1800년 청은 만주·몽골·신장·티베트까지, 조선은 한반도 전체, 에도 막부는 일본 전체 등). 수도 가까운 땅은 본토, 먼 땅은 변경(병력 절반·충성 65).
- **관전 모드**: 컴퓨터끼리 진행되는 판을 보다가 원하는 나라로 난입. 관전 중 금·병력·장수 지원 가능.
- **옵션(판마다)**: 지도/병력 공개, 탐색 지역 기억, 전투 다시보기(1·2배속, 건너뛰기). 나라 이름 변경. 2턴 = 한 계절.
- **승리**: 육지 100% 점령 또는 모든 국가 멸망·속국화.

## 폰에서 하기
- **웹(추천)**: GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면, 푸시할 때마다 `.github/workflows/pages.yml`이 `https://arkhyeon.github.io/table-war/`에 올립니다. 폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 실행되고, 한 번 연 뒤에는 오프라인에서도 열립니다(진행은 폰 브라우저에 저장).
- **파일 하나로**: `npm run build:single` → `dist/table-war.html` 한 파일로 묶임. PC에서는 더블클릭으로 바로 실행, 안드로이드는 크롬으로 열면 됨(아이폰은 파일 앱 미리보기에서 스크립트가 안 돌아가 웹 방식 권장).
