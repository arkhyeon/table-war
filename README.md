# ⚔️ Table War

역사 속 문명과 장수로 펼치는 턴제 땅따먹기 전략 게임 (React + Vite).

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 정적 빌드
```

## 시나리오
- **랜덤 대륙**: 시드로 생성되는 가상 대륙, 무작위 문명·국가 배치
- **세계사 1200년 / 동아시아 650년 / 삼국지 200년 / 유럽사 1400년 / 아프리카사 1400년**: 실제 해안선(Natural Earth)·산맥·강·사막 + 역사적 국가·군주 배치. 시드는 지역 구획을 바꿉니다.

## 규칙 요약
- **병력·이동**: 지역 숫자 = 병사 수(천·만). 인접 지역으로 이동·공격, 지형·도강 보정.
- **바다**: 바다는 구역으로 나뉨. 항구(또는 수군 장수)에서 승선 → 한 구역씩 항해 → 상륙(-25%). 적 함대는 해전으로 돌파, 함대로 바닷길 봉쇄 가능. 내 함대가 있는 바다는 보급로.
- **시간·날씨**: 4턴 = 한 계절, 16턴 = 1년. 북쪽은 눈, 남쪽은 가뭄이 잦지만 남쪽은 풍년도 잦아 연간 손익이 비슷.
- **경제**: 세금 자동 징수, 세율은 국가 일괄 + 지역별 개별. 유지비는 1명 단위(2,500명당 1금) + 장수 녹봉 + 영토 15곳 초과 통치비.
- **징병**: 인원 직접 지정. 1천 명당 3금, 민심은 인구 대비 징병 비율만큼, 인구 감소.
- **민심**: 점령지는 낮게 시작, 25 미만이면 반란. 진휼(비싸고 6턴 쿨다운), 계엄(대군 주둔 시 반란 불가·회복 둔화), 인덕·치안 장수.
- **보급**: 수도와 끊긴 지역은 매 턴 병력 1~10% 감소·전투력 -20%.
- **공성**: 포위(성벽만 깎음, 공성병기·공성 장수로 가속) 또는 강습(즉시 함락 시도, 성벽 효과 2배·손실 1.5배).
- **장수**: 무관·문관 구분, 특성 29종(Ⅰ~Ⅲ 등급). 전투·통치로 레벨업, 특성 승급·추가와 칭호.
- **일기토**: 공격·강타·방어·반격 4수. 균형점에서 네 수가 모두 쓰이도록 피해 배수 조정, AI는 간파·버릇 읽기. 기마 장수가 달려와 맞붙는 애니메이션.
- **사건**: 시나리오별 역사 사건과 무작위 사건을 카드로 알림.
- **세력 균형**: 국력이 평균 2배 초과 시 주변국 경계, 1위가 2.5배 초과 시 대동맹(AI 회원국끼리 휴전·패권국 집중, 방어 +15%).
- **옵션(판마다)**: 지도/병력 공개, 탐색 지역 기억, 시야 내 전투 다시보기(건너뛰기). 📽️ 연대기.
- **승리**: 육지의 60% 점령 또는 모든 국가 멸망·속국화.
