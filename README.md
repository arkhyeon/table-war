# ⚔️ Table War

역사 속 문명과 장수로 펼치는 턴제 땅따먹기 전략 게임 (React + Vite).

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 정적 빌드
```

## 시나리오
- **랜덤 대륙**: 시드로 생성되는 가상 대륙, 무작위 문명·국가 배치
- **세계사 1200년 / 동아시아 650년 / 삼국지 200년 / 유럽사 1400년 / 아프리카사 1400년**: 실제 해안선(Natural Earth)·산맥·강·사막 + 역사적 국가·군주 배치. 시드는 지역 구획을 바꿉니다.

## 규칙 요약
- **병력·이동**: 지역 숫자 = 병사 수(천·만). 인접 지역으로 이동·공격, 지형(숲·구릉·험산·고산)·도강·항해 보정.
- **경제**: 세금 매 턴 자동 징수, 세율은 국가 일괄 + 지역별 개별 설정. 병력 2,500명당 1금 유지비, 장수 녹봉 1금. 징병은 금과 인구 소모.
- **민심·반란**: 점령지는 낮은 민심에서 시작, 25 미만이면 반란. 대제국일수록 통치 부담.
- **보급**: 수도와 연결이 끊긴 지역은 병력 감소·전투력 -20%.
- **공성**: 성벽 내구 3, 0이 되어야 함락. 포위가 없으면 매 턴 복구.
- **날씨·계절**: 1턴 = 한 계절. 비·눈·폭풍·가뭄·풍년이 전투·이동·세수에 영향.
- **사건**: 시나리오별 역사 사건 + 무작위 사건(역병·메뚜기·금광·의용군).
- **장수**: 낮은 기본 출현 확률(6%)에 공평 보정·민심·국고·평판 반영. 전투로 레벨업·칭호. 포로 등용·처형·석방, 회유.
- **일기토**: 공격·강타·방어·반격 4수 상성, 지력이 높으면 상대 수 간파. 승리 시 전투력 +15%.
- **외교**: 동맹·불가침·속국·공동공격·금/영토 거래. 영토 30% 이상 강대국은 견제를 받음.
- **옵션(판마다)**: 지도 전체 공개, 병력 전체 공개, 탐색 지역 기억, 전투 다시보기(시야 안 전투만, 건너뛰기 가능). 📽️ 연대기로 영토 변화 재생.
- **승리**: 전체 지역 60% 점령 또는 모든 국가 멸망·속국화.
