# ⚔️ Table War

역사 속 문명과 장수로 펼치는 턴제 땅따먹기 전략 게임 (React + Vite).

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 정적 빌드
```

## 시나리오
- **랜덤 대륙**: 시드로 생성되는 가상 대륙(대륙/양대륙/군도 유형), 무작위 문명·국가 배치. 섬나라 1곳 이상 보장, 3지역 이하 자투리 섬은 키우거나 제거, 산 12~18%·절벽 해안 18% 상한
- **세계사 1200년 / 동아시아 650년 / 삼국지 200년 / 유럽사 1400년 / 아프리카사 1400년**: 실제 해안선(Natural Earth)·산맥·강·사막 + 역사적 국가·군주 배치. 지도는 고정(시드는 랜덤 대륙에서만).

## 규칙 요약
- **병력·이동**: 지역 숫자 = 병사 수(천·만). 인접 지역으로 이동·공격, 지형·도강 보정.
- **바다**: 바다는 구역으로 나뉨. 승선 → 한 구역씩 항해 → 상륙(-25%), 험한 해안은 절벽 상륙(-55%, 행동력 +1). 해전·봉쇄, 제해권 보급. 바다 날씨: 풍랑·순풍·용오름·해무·폭풍.
- **시간·날씨**: 2턴 = 한 계절, 8턴 = 1년. 북쪽은 눈, 남쪽은 가뭄이 잦고 남쪽은 풍년도 잦아 손익 균형.
- **금**: 병사 1명 유지비 = 1금/턴 기준으로 모든 금액이 정수. 장수 녹봉 2,500금, 영토 15곳 초과 통치비 1,250금/곳.
- **징병**: 징집(1명당 5금, 인구의 5%를 넘게 뽑으면 민심 하락) 또는 모병(1명당 12금, 민심 영향 없음).
- **자원병**: 민심 60 이상이면 매 턴 자원 입대, 나라가 위태로우면 4배.
- **민심**: 점령지는 낮게 시작, 25 미만이면 반란. 진휼·계엄·인덕/치안 장수.
- **보급·공성**: 보급 끊김 시 병력 1~10% 감소. 포위/강습, 공성병기.
- **장수**: 무관·문관, 특성 45종(Ⅰ~Ⅲ). 장수는 병사 수가 아닌 공격·방어 배율을 올림. 이름 변경 가능.
- **일기토**: 반격 > 공격 > 방어 > 반격 가위바위보, 같은 수는 서로 절반 피해. 다그닥 질주·충돌 애니메이션, 승부 결과를 크게 표시, KO 시 50% 전사. 무력 85%·지력 15%의 전장 감각 차이만큼 상대 의도를 미리 간파(힌트 표시), 상대도 내 수를 읽고 바꿀 수 있음.
- **장수 등급**: F·E·D·C·B·A·S·SR·SSR (잘하는 두 능력 70% + 평균 30%), 성장하면 갱신.
- **공평한 무작위 능력치(기본)**: 역사 장수의 성향(가장 높은 두 능력)만 살리고 수준은 무작위. 나라별 장수 점수 합을 맞춰 뛰어난 장수가 있으면 다음 장수는 약하게. 설정에서 역사 능력치로 전환 가능.
- **태수**: 주둔 장수 중 정치 최고가 태수(문관 전효과, 무관 절반) — 세수·민심 보너스.
- **정전**: 6턴 휴전. 땅을 잃는 쪽이 원하고, 후반 1위는 거부.
- **난이도**: 쉬움/보통/어려움 — 컴퓨터 세수 -15%/0/+20%, 초기 병력 85%/100%/120%.
- **업적 10종 · 승리 요약**: 영토 추이 그래프, 최다 전공 장수, 주요 사건.
- **통일선**: 기본 60%, 세계사 30%, 동아시아 45%, 임진왜란 50%.
- **지역 크기(맵 세분화)**: 큼직하게/보통/잘게/아주 잘게 — 지역 수 약 0.6/1/2.3/4배. 세분화해도 인구·병력 총량은 비슷하게 보정, 나라 시작 영토는 비례 확대. 잘게 할수록 판이 길어짐.
- **연도별 세계사**: 기원전 220년 · 1000년 · 1200년 · 1500년 · 1800년 (타임라인에서 선택).
- **지역사**: 전국칠웅 BC 260, 포에니 전쟁 BC 218, 삼국지 200, 광개토대왕 400, 동아시아 650, 유럽 1400, 아프리카 1400, 일본 전국시대 1560, 임진왜란 1592, 나폴레옹 1805.
- **실제 지명**: 역사 지도는 지명 사전(약 890곳, 시대별 옛 이름·건설/소멸 연도 반영)으로 지역 이름을 붙임. 역사 지도는 시드와 상관없이 지도·지명이 고정(시드는 장수·사건 등 게임 진행만 바꿈).
- **해협**: 간몬·쓰가루·도버·메시나·외레순·케르치·보스포루스·다르다넬스·지브롤터 등은 해협 경로로 직접 연결.
- **바다 구역**: 지역사 지도는 해안에서 8칸, 세계 지도는 5칸까지 — 동해 횡단·대서양 횡단 가능.
- **세계판 지역사**: 지역사(전국시대·광개토 제외)는 「🌍 전 세계」로도 시작 가능 — 무대는 잘게 나뉘고, 바깥은 그 시대의 다른 나라들(로마·파르티아·굽타·티무르·무굴 등)로 채워 뒤가 비지 않음. 승리 30%.
- **밀도별 지역 크기**: 지명이 빽빽한 곳(일본·유럽 등)과 해안 땅은 잘게, 시베리아처럼 빈 땅은 크게 나눔.
- **험산 경계**: 험산은 타일이 아니라 경계선에 걸림(경계선 위 작은 봉우리). 그 경계로 넘으면 공격 -35%·행동력 +1(산악 장수 경감), 다른 경계로 돌아가면 페널티 없음.
- **2칸 행군**: 내 땅으로만 이어진 길이면 한 번에 2칸까지 이동.
- **안개**: 시야 밖은 바다까지 완전히 덮음. 땅이 아닌 곳(빙하·고산 등)은 이름 없음.
- **장수**: 능력치·특성 모두 무작위, 나라별 총합만 공평하게(역사 능력치 옵션 별도).
- **동시 턴제(이동 계획)**: 이동·공격은 계획만 세우고(병력 출발, 화살표 표시, 취소 가능) 턴 종료 때 모든 나라의 계획을 함께 처리. 목적지마다 아군 증원 먼저, 적대 부대는 큰 순으로 차례로 공격. 컴퓨터는 플레이어 계획을 모른 채 계획. 플레이어 일기토는 그 전투 차례에 창으로 진행.
- **장수 동행**: 이동 창에서 함께 갈 장수를 골라 군대와 함께 이동.
- **실제 지명 약 98%**: 지명 사전 약 890곳(도시·지방·지형) → 지명이 든 지역, 가까운 미사용 지명, 그래도 남으면 '○○ 북부' 식 방위형.
- **천도**: 금·3AP, 12턴에 한 번. 컴퓨터도 수도가 위험하면 천도.
- **랜덤 지도**: 대륙판(기울어진 타원) + 도메인 왜곡 해안선 + 굽은 산맥 줄기. 유형: 대륙들·판게아(내해)·군도·반도.
- **모바일**: 정보 패널은 바텀시트, 두 손가락 확대, 폰 화면에 맞춘 첫 화면.
- **실제 역사 연표**: 그 해가 되면 '실제 역사' 카드와 함께 이 세계의 같은 나라 영토·순위를 비교해 보여줌.
- **교착 방지**: 사방이 동맹·조약으로 막힌 컴퓨터는 가장 약한 조약 이웃과 관계를 끊고 확장. 동맹이 많을수록 새 동맹을 꺼림. 큰 지도는 행동력 상한이 지도 크기에 비례.
- **병력 그림·애니메이션**: 병력 규모별 병사 1~4명(8만↑은 군기), 대기 중 들썩임. 이동·공격하면 부대가 행군하고, 전투 지점에 💥, 점령 시 지역이 국가색으로 번쩍임. 설정에서 끌 수 있음.
- **후반 패권 경쟁**: 35턴 이후 1위(육지 22%↑)는 행동력 +1~2·적극 징병·불가침 파기까지 하며 공세. 대동맹은 30턴 이후 더 쉽게 결성되고, 연합군 공격 +10%·후방국 군자금 지원으로 역전 가능. 20턴 지나면 내분으로 와해(10턴 재결성 불가).
- **원군**: 동맹국 땅으로 병사(장수 제외)를 보내 넘겨줄 수 있음. AI도 위협받는 동맹국에 원군 파견.
- **망국의 왕**: 정복·병합으로 멸망한 나라의 군주는 승자의 장수로 귀순.
- **신흥국**: 10턴 이후 가끔 새 나라가 출현 — 빈 땅의 봉기, 민심 30 미만 변방의 독립(떠돌이 장수나 역사 장수가 군주), 충성 낮은 옛 군주의 부흥(8턴 이후).
- **속국 병합**: 10턴 이상 거느린 속국을 국력 2배 이상이면 병합(행동력 2, 평판 -5).
- **전투 종류**: 야전·공성전·도하전·해협 도하·해전·상륙전·절벽 상륙전으로 구분해 다시보기에 표시.
- **사건**: 역병·홍수·지진·금광·교역 호황·해적·도적·용병단·장수 출분 등 어느 나라에나.
- **세력 균형**: 국력 평균 2배 초과 시 견제, 1위가 2.5배 초과 시 대동맹.
- **관전 모드**: 컴퓨터끼리 진행되는 판을 보다가 원하는 나라로 난입. 관전 중 금·병력·장수 지원 가능.
- **옵션(판마다)**: 지도/병력 공개, 탐색 지역 기억, 전투 다시보기(1·2배속, 건너뛰기). 나라 이름 변경. 2턴 = 한 계절.
- **승리**: 육지의 60% 점령 또는 모든 국가 멸망·속국화.
